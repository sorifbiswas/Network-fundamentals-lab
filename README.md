
Network Fundamentals Lab

A beginner-friendly practical networking lab designed to learn computer networking through Python, Bash scripting, and technical documentation.

## Project Objectives

- Understand computer networking fundamentals.
- Learn IP addressing and subnetting.
- Understand TCP and UDP protocols.
- Learn how DNS works.
- Explore common network ports.
- Practice Linux networking commands.
- Build basic networking tools using Python.
- Develop practical troubleshooting skills.
