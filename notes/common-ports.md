
# Common Network Ports

A port identifies a network service or application endpoint.

## Common Ports

| Port | Protocol / Service |
|---|---|
| 20 | FTP Data |
| 21 | FTP Control |
| 22 | SSH |
| 23 | Telnet |
| 25 | SMTP |
| 53 | DNS |
| 67 | DHCP Server |
| 68 | DHCP Client |
| 80 | HTTP |
| 110 | POP3 |
| 123 | NTP |
| 143 | IMAP |
| 443 | HTTPS |
| 3306 | MySQL |
| 3389 | RDP |
| 5432 | PostgreSQL |
| 8080 | Alternative HTTP |

## Security Note

An open port does not automatically mean a vulnerability exists. Security depends on the service, configuration, exposure, and applicable protections.
